# Supabase 구성

이 포트폴리오는 Supabase를 데이터베이스·로그인·파일 저장소로 사용합니다.
연결 설정은 `src/config.js` 에 있습니다. (공개용 publishable 키만 사용하며, 데이터 보호는 Supabase의 RLS 정책이 담당합니다.)

## 사용하는 테이블
| 테이블 | 용도 | 화면 |
| --- | --- | --- |
| `profile` | 이름, 소개, 소셜 링크 등 프로필 정보 | 홈, 소개 |
| `projects` | 연구용 게임·오락 게임 (`kind` 로 구분) | 연구용 게임, 오락 게임 |
| `papers` | 논문 (`state` 로 집필 중/등재 구분) | 논문 |
| `events` | 전시·발표 일정 | 전시·발표 |
| `logs` | 프로젝트 일지(그림일기) | 일지 |

## 로그인
- 관리자 화면은 Supabase Auth 의 이메일·비밀번호 로그인을 사용합니다.
- 방문자는 읽기만 가능하고, 로그인한 관리자만 글을 추가·수정할 수 있습니다.

## 파일 저장소
- Storage 버킷 이름: `portfolio-media` (이미지·영상 업로드)
